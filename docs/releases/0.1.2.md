Small update: a setting for the window stacking and a better card layout on wide screens.

## What changed
- **Keep the window above the other applications is now a setting.** In **Settings → Application**. It is on by default, as before. Turn it off and the system decides the stacking: an application opened later appears above AnkiMining instead of below it. The popup and the region selector still show over the text they belong to.
- **The explanation of the card no longer stretches on ultrawide screens.** In the note type the app creates, the meaning is a left-aligned block, centered on the card, at most 700 px wide. A note type you already have keeps its styling; to get the same layout, open it in Anki (*Tools > Manage Note Types > Cards > Styling*) and replace `.meaning { margin: 12px 0; }` with `.meaning { max-width: 700px; margin: 12px auto; text-align: left; }`.
- **README rewritten** around what the app does.

## Install and update
Installed apps offer this version by themselves (a banner with **Install and restart**). Or download it: Windows `AnkiMining_0.1.2_x64-setup.exe` (not signed by Microsoft: SmartScreen may warn, choose *More info* > *Run anyway*), Linux `AnkiMining_0.1.2_amd64.AppImage`.
